# 汇报

- `slides.tex`：7 页中文 Beamer，16:9，目标讲述约 4—5 分钟。
- `discovery.pdf`：2024 年问题发现图。
- `validation.pdf`：2025 年主验证及天气分层汇总图。
- `speaker_notes.md`：逐页讲稿与建议时间，不参与编译。

在 TexPage 新建空白项目，将 `slides.tex` 的全部内容复制到同名文件，上传两个 PDF 图片，三者放在项目同一目录。设置主文件为 `slides.tex`、编译器为 **XeLaTeX**，TeX Live 可选 2025 或更新版本，再编译并导出 PDF。PDF 图片无需转成 PNG。

使用 CTeX 的 Fandol 字体，不需上传字体、模板或其他源码。姓名、学号、单位均位于 `slides.tex` 导言区，可直接修改。按 [TexPage 官方教程](https://www.texpage.com/docs/en/learning/chapter-0/)选择 XeLaTeX。
