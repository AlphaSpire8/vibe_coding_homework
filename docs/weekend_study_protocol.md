# 周末节律差异：验证方案

## 问题与假设

用户已选择 A：**非会员的周末/平日日均行程比是否高于会员？**

研究总体为既定筛选口径下的 Divvy 行程，沿用清洗、车型、站点完整性及冲突 ID 规则。member/casual 是行程标签，不是独立用户身份。

2024 年用于发现问题，2025 年用于验证。本方案和 [机器可读配置](../configs/weekend_validation.json) 在读取 2025 年行为或天气关系前提交审阅；本阶段只检查 2024 年天气与日期的设计可行性。

设 `Y[g,d]` 为第 d 天第 g 组的筛选行程数：

```text
R[g] = 周末日均行程数 / 平日日均行程数
Q    = R[casual] / R[member]
H0   : Q ≤ 1
H1   : Q > 1
```

主分析报告两个 R 和 Q，不直接用周末总量除以平日总量。2024 年发现值约为 R[casual]=1.58、R[member]=0.77、Q=2.05；它们不作为新验证结果。Q>1 只说明相对组间节律差异，不要求非会员在每个月的周末绝对量都更多。

## 1. 全年主验证

- 范围固定为 2025-01-01 至 2025-12-31，按原始出发本地日期归类。周六、日为周末，其余为平日；不重新标记节假日。
- 日历有 365 天：104 个周末日、261 个平日。两组使用相同日期；没有该组行程且全量来源当天有记录时记为 0。
- 若出现无来源记录日，先暂停并核查完整性，不能当作 0。缺失 ID、异常时间等不再另拟规则，继续沿用已确认筛选。
- Q 由全年两个 R 相除。另列 12 个月的 Q 和天数，作为异质性描述，不把“12 个月必须全部同向”增加为事后主判据。
- 四个组别×日类型总量均须大于 0；否则不加伪计数，报告主指标不可估。

### 近似不确定性与判据

以自然周为配对重抽样块，两组在同一块中一起抽取，保留块内日期、周末标记及行程数。周键使用周一日期，避免不同年份的同一 ISO 周号被合并；年首尾不完整周仍保留。

按每块首个实际观测日的月份分层，各月有放回抽取原块数，重复 10,000 次，随机种子 20261109。每次重新计算日均量和 Q，报告第 2.5%、97.5% 分位区间。跨月周按块首日归类，月份构成仅近似保留；不把会员和非会员分别独立抽样。

该区间用于观察按日期块重抽样的稳定性，仍依赖周块可近似交换等假设，不是独立用户的抽样误差或因果区间。分块旨在保留部分相邻日期结构；时间序列重抽样需考虑相关性的理由见 [Hyndman 与 Athanasopoulos 的时间序列 bootstrap 说明](https://otexts.com/fpp3/advanced.html#bootstrapping-time-series)。本方案的自然周和月份分层是课程中的近似设计，并非该文具体算法。

| 情况 | 主结论表述 |
| --- | --- |
| Q>1，且区间下界>1 | 在该筛选口径与重抽样假设下，获得初步支持 |
| Q>1，但下界≤1 | 方向一致，不确定性仍不足以排除边界 |
| Q≤1 | 本次验证未支持预期方向，报告实际估计和区间 |
| 指标不可估，或有效重抽样不足 99% | 不能完成主判定，报告原因，不改变预设规则 |

不另报告按数百万条行程独立检验的 p 值。

## 2. 额外实验：月份与天气分层

用户选择较细的分层比较，并在仅看 2024 年天气覆盖后确认 **10°C** 粒度。

| 维度 | 固定规则 |
| --- | --- |
| 月份 | 1—12 月分别处理 |
| 气温 | `(TMAX+TMIN)/2`，以 0°C 为原点的 10°C 左闭右开区间；例如 -1°C 属于 [-10,0) |
| 无雨 | PRCP=0 且无 T 微量标记 |
| 微量/不足 1 mm | 有微量标记的零值，或 0<PRCP<1 mm |
| 雨日 | PRCP≥1 mm |
| 共同支持 | 同一格至少 2 个周末日、2 个平日；仅依据天气和日期确定，不按效应筛格 |

天气仍用 O’Hare。缺失或不可用天气不补零，只从额外实验中排除，并单独报告日期数；不因此删改全年主分析。

每个共同支持格 s 内计算 Q[s]，再以该格日期数占共同支持总日期数的比例为权重，计算 Q[s] 的**加权几何平均**。这相当于对 log Q[s] 做日期数加权平均后取指数，不按行程量加权。

同时报告：

1. 全年未分层 Q；
2. 仅共同支持日期的未分层 Q；
3. 同一批共同支持日期的分层汇总 Q；
4. 每格 Q、平日/周末日数、覆盖月份及占全年日期比例。

后两者比较时也要说明权重和统计目标不同；不能把总体数值差异直接解释成“天气解释了多少差异”。

额外实验只提供方向性稳健性描述，不另作分层显著性检验。至少有 5 个共同支持格才给总体汇总；若任一支持格的四组总量含 0，则总体对数汇总标为不可估，保留原格及计数，不临时剔格、加伪计数或放宽阈值。

若共同支持不足，或分层方向与主结果不同，如实报告适用范围与不一致；主判据不因额外实验的结果而切换。

## 3. 执行与交付

本阶段交付方案、配置和发现年可行性审计；下一阶段按审阅后的方案执行 2025 年主验证及额外实验，再整理结论。

预计输出两个 R、主 Q 与稳定性区间、12 个月 Q、天气分层及共同支持覆盖、完整运行清单。汇报可优先使用“两组节律对比”和“2025 年验证及天气分层结果”两张图，具体版式在结果产生后安排。

所有结论限于信息完整且通过既定规则的行程。车型选择偏差、单站天气代理、节假日、系统运营和个体身份缺失仍是局限；不声称因果，也不把 2024、2025 当作完全独立个体样本。
